# float-Yyk 公开版范围

本仓库提供可独立部署的完整应用快照。后续更新按需整理，不与上游自动同步。

[返回首页](../README.md) · [部署说明](DEPLOYMENT.md) · [已知问题](SUPPORT.md)

当前版本1.2.0的增量见 [更新说明](releases/1.2.0.md)。

## 保留的定制功能

- 聊天：经典与玻璃 iMessage 外观、气泡配色、消息回应与文字特效、双语显示、群聊互动与导演旁白。
- 角色与身份：身份数据隔离、角色互动范围、聊天应用头像同步、头像历史与换回。
- 多媒体：多图与照片标记、共享相册、绘画互动、音乐分享、歌词卡及持续一起听。
- 其他：外币转账与钱包显示、快捷回复窗口，以及已集成的聊天与媒体修正。

## 原版能力与本次边界

- 保留原版短期、长期、核心记忆与向量召回；不包含定制记忆增强、认知注入或新版记忆界面。
- 保留原版独家特调基础功能；不包含定制酒馆兼容层。
- 外观只提供经典、玻璃；不包含 SP。
- 不包含私人开发日志、版本备份及尚未发布的实验模块。
- 预设、世界书和正则仍可按应用现有方式导入编辑。

## 部署

直接部署本仓库的 main，无需再部署原版仓库。应用默认名为 float-Yyk，默认开启单机模式。可选云端、音乐和模型服务使用部署者自己的配置，参见 README 与 .env.example。

网页／PWA 与原版同时使用时，应部署到不同网址。安卓壳的 applicationId 也与原版分开；安卓构建需要另行验收。
