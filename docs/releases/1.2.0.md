# 1.2.0 · 2026-10-24

- 自动回复：会话独立开关与等待时间；普通发送后可自动回复，发送并回复仍立即触发。
- 重试版本：比较原文与历次版本、保留所选版本、从旧版本继续重试，支持中断与失败恢复。
- 语音与翻译：Fish Audio、自选模型且不自动切换，Fish/ElevenLabs独立表达指南；原译文点击切换和引文翻译优化。
- 聊天记录转发：原消息外观、语音波形、表情与转账卡片，详情顶栏适配安全区；支持用户和角色发布静态聊天长图到朋友圈，并按发布者切换左右视角。
- 一起听整体更新：播放器与音乐页面、歌词选择/分享、封面与加入动效；私聊/群聊邀请、成员分别加入/拒绝/退出、共同歌单新建/改名/找歌入单/收藏/移除、有效播放时长榜单。角色可主动邀请和整理歌单，普通分享与邀请分开。
- 合并悬浮工具：提示词、API、世界书与快捷入口，拖动贴边、位置记忆及固定高度滚动候选。
- 用户资料：聊天头像与档案头像分离、活动头像回退、可选用户肖像和外貌描述。
- 预设管理：参数发送控制、应用/场景范围、分组/排序/多选归组、复制/替换/导入导出。
- 其他设置：API复制和模型整理、数据管理分区/日夜布局、相册默认图标换肤。

徽章计时解锁尚未完成，本版不包含试戴入口或试戴数据。升级前请导出重要数据备份；在自己的fork同步main后重新部署。已有的1.1.1身份备份、恢复和存储保护继续保留。
